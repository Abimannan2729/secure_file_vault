# Secure File Vault

A MERN stack application with robust authentication (JWT + Refresh Tokens), Redis caching, and OTP verification.

## Structure
- `/backend`: Node.js/Express API
- `/frontend`: React Client

## Getting Started
1. `cd backend` && `npm install`
2. `cd frontend` && `npm install`
3. Setup `.env` in both directories.
4. Run `docker-compose up` for DBs.
5. Start backend and frontend servers.
